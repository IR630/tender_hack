# Яндекс Маркет: обзор для нового человека

Как мы получаем цены с market.yandex.ru.

**Код:** `backend/app/scrapers/yandex_market.py`  
**Техническая шпаргалка:** [yandex-market.md](yandex-market.md)

---

## В двух словах

Яндекс Маркет отдаёт **HTML-страницу** поиска, а не JSON. Мы:

1. Качаем страницу «как браузер» через **curl_cffi**.
2. Разбираем HTML библиотекой **selectolax** (ищем блоки `article` с товарами).
3. Для каждого товара **докачиваем карточку** — описание и характеристики.
4. Если curl не сработал — включается запасной **Playwright** (настоящий headless Chrome).

Typical time: **5–20 секунд**.

---

## Пайплайн

```
Запрос + регион
      │
      ▼
 Redis-кэш? → hit → готово
      │
      miss
      ▼
 [1] curl: зайти на market.yandex.ru, выставить cookie региона
 [2] curl: открыть /search?text=... (до 3 страниц)
 [3] распарсить snippets (название, цена, ссылка, картинка)
 [4] отфильтровать мусор (чехлы, кабели…) и дубликаты
 [5] параллельно (4 потока) скачать карточки товаров
      │
      ▼
  Если товаров 0 → Playwright делает то же самое через браузер
      │
      ▼
  Список Product → UI
```

---

## Главный файл: `yandex_market.py`

| Часть | Зачем |
|-------|-------|
| `_fetch_products_sync` | Основной путь через curl |
| `_fetch_with_playwright` | Запасной путь, если curl пустой или ошибка |
| `_parse_search_html` | Достать товары из HTML выдачи |
| `_collect_paginated_products` | Пройти несколько страниц поиска |
| `_enrich_products` | Добавить описание с карточки |
| `_is_garbage_listing` | Отсечь аксессуары, если пользователь искал не их |

---

## Регион

Cookie **`yandex_gid`** — число из `core/regions.py` (Москва = `213`). Без него выдача может быть «чужого» города.

---

## Фильтрация «мусора»

В коде есть список слов: чехол, стекло, кабель, зарядка… Если в названии товара есть такое слово, а в **запросе пользователя** нет — товар выкидываем.

Это эвристика, не нейросеть. Планировалось заменить на ML-ранжирование.

---

## Enrichment (обогащение карточки)

Snippet на странице поиска — короткий. После сбора списка мы **отдельно** заходим на URL каждого товара (до 4 одновременно) и вытаскиваем:

- текст описания;
- характеристики (`data-auto="product-spec"`);
- склеиваем в поле `description` для UI.

---

## Кэш

Redis: `ym:search:{регион}:{запрос}` — как у WB.

---

## Блокировки

Если в HTML есть `smartcaptcha` или короткая страница 403 — считаем, что Яндекс нас не пустил. Тогда пробуем Playwright или возвращаем ошибку.

## Библиотеки (что за что)

| Библиотека | Роль |
|------------|------|
| curl_cffi | HTTP «как Chrome» |
| selectolax | Быстрый разбор HTML |
| playwright | Fallback-браузер |
| ThreadPoolExecutor | Параллельная загрузка карточек |

## Место в общем поиске

**Параллельно** с Wildberries. Результаты появляются на экране раньше, чем Ozon.
