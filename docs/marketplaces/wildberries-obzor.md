# Wildberries: обзор для нового человека

Как мы получаем цены с Wildberries — простым языком.

**Код:** `backend/app/scrapers/wb.py`  
**Техническая шпаргалка:** [wildberries.md](wildberries.md)

---

## В двух словах

Wildberries — **самый простой** источник в проекте. Мы не открываем браузер и не парсим HTML. Делаем **один HTTP-запрос** к официальному JSON API и получаем список товаров.

Typical time: **1–3 секунды**.

---

## Как это выглядит для пользователя

```
Вы ввели «наушники» + регион Москва
         │
         ▼
   Есть ответ в Redis-кэше?
         ├─ да  → сразу отдаём сохранённые товары
         └─ нет → один запрос к search.wb.ru
         │
         ▼
   До 30 товаров → экран приложения
```

---

## Главный файл: `wb.py`

| Что делает | Простыми словами |
|------------|------------------|
| `WildberriesScraper.search()` | Точка входа: принимает запрос, возвращает список `Product` |
| `_fetch_search_sync()` | Синхронный HTTP GET к API WB |
| `_assemble_products()` | Превращает JSON WB в наши объекты |
| `_throttle_wb()` | Пауза ~1.5 с между запросами — чтобы WB не заблокировал IP |
| Circuit breaker | Если WB два раза ответил 429 — не долбим его 10 минут |

---

## Откуда берутся данные

**URL:** `https://search.wb.ru/exactmatch/ru/common/v4/search`

**Библиотека:** `curl_cffi` — притворяется браузером Chrome (TLS fingerprint), иначе WB часто отвечает 429.

**Регион:** параметр `dest` — число из `core/regions.py` (для Москвы это `-1257786`).

| Поле в приложении | Откуда в JSON WB |
|-------------------|------------------|
| Название | `name` |
| Цена | `sizes[0].price.product` (уже в **копейках**) |
| Ссылка | `wildberries.ru/catalog/{id}/detail.aspx` |
| Картинка | собирается по таблице basket-CDN из id товара |
| Бренд, продавец | `brand`, `supplier` |

---

## Чего мы **не** делаем (намеренно)

- Не открываем карточку товара отдельно (нет enrichment).
- Не используем Playwright.
- Не листаем вторую страницу поиска — только `page=1`, max 30 товаров.

Так меньше шансов, что WB заблокирует наш IP.

---

## Кэш

Ключ в Redis: `wb:search:{регион}:{запрос}`.

Повторный поиск тем же текстом в том же регионе — без запроса к WB.

---

## Если что-то пошло не так

| Симптом | Что значит |
|---------|------------|
| Пустой блок WB + текст ошибки | 429/498, circuit breaker, или WB вернул 0 товаров |
| «Временно недоступен… 10 мин» | Сработал circuit breaker после блокировок |
| VPN / не-RU IP | WB часто режет такие запросы |

Ошибка попадает в `SearchGroup.error` — фронт показывает её под блоком Wildberries.
