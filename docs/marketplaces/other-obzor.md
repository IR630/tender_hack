# Другие источники: обзор для нового человека

Четвёртый блок в UI — «Другие источники». Сейчас это **заглушка**.

**Код:** `backend/app/sources/other/search.py`  
**Техническая шпаргалка:** [other.md](other.md)

---

## В двух словах

Идея проекта — искать цены не только на WB, Ozon и Яндекс Маркете, но и на **других сайтах** Рунета (магазины, прайс-агрегаторы).

**Сейчас в коде:** функция `search_other_sources` всегда возвращает **пустой список** `[]`.

На экране пользователь видит блок «Другие источники» с нулём товаров — это нормально, не баг.

---

## Что делает файл

```python
async def search_other_sources(request):
    resolve_region(request.region)  # регион читаем, но не используем
    return []
```

Всё. Никаких HTTP-запросов.

---

## Что планировалось (architecture.md)

```
Запрос пользователя
      │
      ▼
 SearXNG — поиск по интернету (не только маркетплейсы)
      │
      ▼
 Вытащить из страницы Schema.org / JSON-LD (структурированные данные о товаре)
      │
      ▼
 При необходимости — vision-модель (цена на скриншоте)
      │
      ▼
 Product с произвольным source_domain
```

Инфраструктура **SearXNG** уже поднята в Docker — её использует запасной путь Ozon (`ozon_public_scraper`), но не этот модуль.

---

## Место в общем поиске

- Запускается **параллельно** с WB и YM в `orchestrator/search.py`.
- В API порядок групп: `wildberries → yandex_market → other → ozon`.
- На фронте «other» показывается **последним** в списке (свой порядок в `App.tsx`).
